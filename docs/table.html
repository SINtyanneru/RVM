テーブル

RVMではメモリのかわりにテーブルという概念が有ります。
テーブルはSQLのテーブルの様に行になっており、
領域を確保した際に自動的に行が追加されます。

プログラムからはリンクを経由して値の取得、変更が出来ます。
リンクは、作成したスレッドからのみ取得/変更の操作が可能です
別のスレッドから操作する場合、リンクを新たに作成する必要が有ります。
[リンク]→[行]→[値]
という形です。
実際に使用する場合、リンクアドレスを用いるだけで自動的に値に変換されます。
また、値は64bitではなく、バイトの配列です。つまりuint8_t[]
なので数値を表現するのなら確保する際にサイズを1にしてはいけません。

リンク

リンクは、テーブルの行への道標です。
内部的にはリンクアドレスと行番号への1対1対応です。
リンクは、作成したスレッドしかさわれません。
別のスレッドから使う場合は、新たにリンクを作る必要が有ります。
この操作のみリンクへ触れることが出来ます。

行

ただの配列

値

データ本体です。

わかりやすく言うと？

Cでいうポインタが行に該当します。
リンクが変数です。
複数のリンクが同じ行を示す、これは複数の変数が同じポインタを示していると考えてください

ガベコレはどうなるの？

RVMではガベコレのかわりにObjCやRustも採用しているカウンタを採用しています。
リンク解除をした際にこのプロセスは実行されます
