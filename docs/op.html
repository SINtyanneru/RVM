即値、仮想レジスタ、テーブルの識別

RVMにはLOAD系命令、STORE系命令、MOV系命令がある。
  • LOADはテーブルからレジスタにロードする。
  • STOREはレジスタからテーブルに
  • MOVは即値をレジスタに
基本的に、算術系命令はレジスタしか受け付けない。
命令によって受け付けるオペランドを変えることで解決した。

エンコード

命令のエンコードは独自方式
Cのstructで表す方がわかりやすいと思うのでそうする
typedef struct {
	//オペコード
	uint8_t opcode;
	//オペランドX
	uint64_t opland_x;
	//オペランドY
	uint64_t opland_y;
	//オペランドZ
	uint64_t opland_z;
} OP;
